# Assets — espace membre Cobblemine

Illustrations générées avec imagegen (outil intégré). Proposition artistique approuvée : blanc, gris froid et orange, univers voxel d’exploration.

- `launcher-landscape.png` : panorama large, arche à droite. Afficher en cover, position right center. Ajouter un dégradé CSS blanc vers transparent à gauche pour garantir la lisibilité du texte.
- `adventurer-avatar.png` : portrait carré de remplacement. Utilisable aussi dans la navigation avec object-fit: cover. Illustration générique, pas le skin réel du membre.
- `cobblemine-cube.png` : proposition d’emblème cubique. Le logo actuel du site n’est pas remplacé.
- `icons/` : 15 SVG à grille 24 px, trait 1.75, currentColor. Intégrer inline pour hériter de la couleur CSS ; ne pas les agrandir comme illustrations. Community est un pictogramme générique, pas le logo Discord.

## Couleurs
Fond #FFFFFF ; fond secondaire #F4F5F7 ; séparations #D9DEE3 ; texte #27313A ; texte secondaire #687481 ; action #FF941F.

## Typographie
Inter pour l’interface ; Rajdhani pour les titres si cohérent avec le reste du site. Garder les textes et boutons en HTML, jamais dans les images.

## Prompts de génération (résumé)
1. Panorama Minecraft cinématique 3:1, arche en pierre à droite, lanternes ambre, montagnes et brume claire à gauche, sans texte.
2. Portrait carré d’un aventurier voxel brun, écharpe orange, veste anthracite et cuir, montagnes et arche en fond, lumière naturelle, sans texte.
3. Emblème cubique isométrique en pierre grise, cristaux ambre incrustés, fond transparent, sans texte.

Assets préparés uniquement. Aucun changement de l’interface, de l’authentification ou des données membre.
